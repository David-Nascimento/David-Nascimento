## Engineering Focus

- **Test Automation** — E2E, Mobile e API automation com BDD, Page Objects e arquiteturas reutilizáveis
- **Mobile Quality** — Appium, estratégias de localização, diagnóstico de falhas e redução de testes flaky
- **Quality Tooling** — gems, CLIs e ferramentas para geração de cenários, diagnóstico e massa de dados
- **API Testing** — automação funcional, contratos, integração e performance
- **Quality Engineering** — CI/CD, relatórios, observabilidade e estratégias de confiabilidade
- **AI for QA** — uso de LLMs para apoiar especificação, geração e análise de testes
