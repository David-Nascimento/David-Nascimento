Engenheiro de QA com foco em automação de testes e no desenvolvimento de ferramentas que tornam a qualidade de software mensurável, reproduzível e acessível. Atuo em automação web, mobile e de APIs no ecossistema Ruby, e construo sistemas com dados públicos abertos em Elixir.

---

### Áreas de atuação

- **Automação de testes** — suítes E2E, mobile e de API com BDD, Page Objects e relatórios rastreáveis
- **Ferramentas de qualidade** — gems e CLIs para geração de cenários, diagnóstico de falhas e massa de dados
- **Dados públicos** — painéis e APIs construídos exclusivamente sobre fontes oficiais abertas
- **IA aplicada a QA** — uso de LLMs para acelerar a especificação e a cobertura de testes
